Architektur & Philosophie

Warum ein eigener Store?

⚡

Schluss mit JAR-Kompilierung

Kein nerviges jarsigner mehr bei jedem Release. BenzStore nutzt direkt geprüfte Einzeldateien und JSON-Feeds auf dem Content-Branch.

🛡️

Echte SHA-256 Integrität

Zero-Dummy-Security: Jedes Paket wird vor der Installation auf Byte-Ebene mit dem Manifest abgeglichen. Manipulationen werden sofort abgewiesen.

🎯

Freier Version-Picker

Installiere entweder die neueste Version (Latest) oder wähle gezielt einen beliebigen früheren Release-Stand mit vollständigem Changelog.

🚀

Linux Single Binaries

Unter Linux landen reine Standalone-Binaries direkt in ~/.local/bin inklusive automatischer .desktop-Starter für dein Anwendungsmenü.

Installation auf deinen Geräten

Android

BenzStore APK installieren

Lade benzstore_1.0.apk herunter und tippe auf Installieren. Aktiviere bei Aufforderung die Berechtigung für unbekannte Quellen.

APK Download (101 KB)
Linux (x86_64)

Native Single Binary

Lade die ausführbare Datei herunter und verschiebe sie in deinen lokalen Pfad:

curl -sL https://raw.githubusercontent.com/benzjeremy/benzstore/content/linux/benzstore/benzstore_1.0 -o ~/.local/bin/benzstore
chmod +x ~/.local/bin/benzstore
benzstore
Windows (x86_64)

Windows App-Mode

Lade benzstore_1.0.exe herunter und starte sie per Doppelklick. BenzStore startet automatisch im schlanken Edge/Chrome App-Modus.
